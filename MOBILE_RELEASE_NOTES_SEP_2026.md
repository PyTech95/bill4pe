# BILL4PE Cross-Platform Release Update

This package is prepared as a shared web + Android + iOS codebase.

## Included

- Same React UI and same FastAPI/MongoDB backend for all platforms.
- `REACT_APP_BACKEND_URL` configuration for web/mobile API connection.
- Capacitor 7 Android/iOS build configuration.
- Native camera/photo receipt capture.
- Native GPS location capture.
- Camera, photos, microphone and location permission declarations generated by the mobile preparation script.
- iPhone safe-area/notch/home-indicator responsive handling.
- Android cutout/small-screen responsive handling.
- Bottom navigation touch targets and narrow-screen text sizing fixes.
- Mandatory 4-digit wallet PIN flow preserved.
- Existing Razorpay wallet recharge and bill-generation charge flow preserved.
- MongoDB payment-proof storage preserved.
- `emergentintegrations==0.2.0` removed; AI uses the configured `GEMINI_API_KEY` directly.

## Production backend CORS

If backend CORS is not `*`, include native app origins:

`https://localhost,capacitor://localhost`

along with the production website origin.
